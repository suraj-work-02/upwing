# Upwia

A freelance portfolio concept for UpWing, a fictional recruitment and career
development brand.

Company names, statistics, testimonials, history, and contact details are
illustrative. The contact form demonstrates validation and confirmation states;
it does not send messages.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Create production build  |
| `npm run start` | Start production server  |
| `npm run lint`  | Run ESLint               |

## Structure

- `app/` - routes (App Router)
- `components/` - layout, home, services, contact, ui, motion
- `content/` - site copy and dummy contact details
- `lib/` - shared utilities

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
